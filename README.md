# Welcome to RubyKaja

RubyKaja is a title to recognize people who have contributed to Ruby or the Ruby community.
Here is the web site for http://kaja.rubyist.net/en .

## Usage

```bash
$ gem install bundler
$ git clone git://github.com/ydah/kaja.git
$ cd kaja
$ bundle install
$ bundle exec jekyll serve
```

Then open http://localhost:4000 in your browser.

## Build for production

```bash
$ bundle exec jekyll build
```

The site will be generated in the `_site` directory.

## Deploy to GitHub Pages

Push to `main` branch with GitHub Actions, or use the `_site` directory as the deploy target.
